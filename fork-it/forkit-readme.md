### Option 2: Fork the repo (I have no idea if the code below is good or not, but Claude has sucked lately, so you're on your own)

1. Click **Fork** at the top of the page.
2. Clone your fork and run the project locally:

```bash
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>
npm install
npm run dev
```

3. Open the local URL your terminal prints, then edit in your code editor of choice.
